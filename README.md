## FAQ

### What is XCutors?

XCutors is a collection of various Roblox executors packaged with a universal loader for easy access on Windows.

### Is this safe to use?

These tools are for educational and customization purposes. Always download from official sources and use at your own discretion.

### Do I need to pay for these executors?

Some included executors like Synapse Z are paid third-party tools. This repository provides a loader, not the licenses.

### What operating system is required?

XCutors is designed specifically for Windows desktop environments (Windows 10/11 recommended).

### How do I update the tools?

Check the GitHub Releases page periodically for updates to the loader or executor compatibility.

### Can I use this on a Mac?

No, these tools are built for Windows only. There is no current support for macOS or Linux.

### Why use a universal loader?

The xcutorsLoader simplifies managing multiple executors, providing a single interface to select and launch your preferred tool.
